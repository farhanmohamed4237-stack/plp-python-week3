# Week 3 Assignment: Conditions and Loops

## Part A: Grade Reporter

**File:** grade_reporter.py

This program uses a for loop and if/elif/else statements to assign grades to five learners. It calculates how many learners passed, how many failed, and the average score.

## Part B: Bug Hunt

**File:** bug_hunt.py

This program fixes three bugs in a while loop and correctly calculates the sum of numbers from 1 to 5.

## Bug Hunt Reflection

The hardest bug to find was the incorrect loop condition because it did not produce an error message. I knew something was wrong because the program ran but produced the wrong total. Checking the expected answer of 15 helped me identify and correct the loop condition.
